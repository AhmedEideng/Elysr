# 📊 GSC Weekly Report — دليل الاستخدام

أسبوعيًا (10 دقايق) بتولّد تقرير فرص الظهور من بيانات Google Search Console
**بدون أي API أو credentials** — export CSV + سكريبت تحليل محلي.

## الخطوات (كل أسبوع):

1. افتح [Google Search Console](https://search.google.com/search-console)
   → **Performance** (الأداء).
2. اختار الفترة: **آخر 28 يوم** (نفّس الفترة كل أسبوع عشان المقارنة).
3. التقرير الافتراضي (Pages) → زرار **Export** (السهم اللي فوق الجدول)
   → **CSV** → احفظه هنا باسم: `scripts/gsc/pages.csv`
4. من الشريط الأفقي فوق الجدول اختار **Queries** → **Export** → CSV
   → احفظه هنا باسم: `scripts/gsc/queries.csv`
5. شغّل:
   ```bash
   npm run gsc
   # أو: node scripts/gsc-report.mjs
   ```
6. التقرير بيطلع في الـ console + ملف Markdown كامل:
   `scripts/gsc/report-YYYY-MM-DD.md`

## إيه اللي في التقرير:

| القسم | بيستخدمه إزاي |
|---|---|
| 📈 الملخص | اتجاه إجمالي (نقرات/ظهورات/CTR/موضع) — قارنه بالتقرير السابق |
| 🎯 فرص الصفحات (موضع 4–10) | الصفحات القريبة من التوب-3 — كل واحدة عليها إجراء مقترح (title/meta vs محتوى/روابط) |
| 🎯 فرص الـ Queries | **مواضيع** بتظهر في 4–10 → فيها فرصة محتوى جديد/تحسين (افحصها ضد عناقيد الـ topics السبعة) |
| ⚠️ ظهورات عالية + CTR ضعيف | title/meta ما بتطابقش الـ query → Rewrite |
| 🏷️ Brand queries | تتبع ظهور "اليسر/elysr" — مقياس انتشار البراند |
| 🔭 صفحات بعيدة (>10) | للمتابعة — مش أولوية |
| ✅ Top 5 actions | قائمة الأفعال الجاهزة للأسبوع |

## ملاحظات:

- بيانات GSC فيها **تأخير ~يومين** — آخر يومين من الفترة ممكن يكونوا ناقصين.
- لو التصدير فيه أبعاد إضافية (country/device/date) السكربت بيقوم
  بالـ aggregation بوزن الـ impressions (نفس حساب GSC).
- الملفات `pages.csv`/`queries.csv` **مستثناة من git** (`.gitignore`)
  عشان بيانات الأداء سرية — بس `sample-*.csv` و`report-*.md` بتتلتزم
  لو حابب (الـ reports مفيدة كسجل أسبوعي).
- عشان تجرب شكل التقرير من غير ملفات: `node scripts/gsc-report.mjs --sample`
- حد أدنى الظورات للفرص: 10 (غيّرها: `--min-imp 20`).
