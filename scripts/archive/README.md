# scripts/archive — أدوات فحص لمرة واحدة

سكربتات استُخدمت في جولة تدقيق محددة وبقيت للتوثيق وإعادة التشغيل عند الحاجة.
**ليست جزءاً من البوابات الدائمة** (تلك في `scripts/` الجذر ولها npm scripts).

| الأداة                          | الجولة                                     | مخرجاتها (جذر المستودع)                             |
| ------------------------------- | ------------------------------------------ | --------------------------------------------------- |
| `audit-product-meta.mjs`        | تدقيق Product Meta ‏2026-09-28             | `AUDIT-PRODUCT-META-2026-09-28.md/.json`            |
| `second-pass-product-audit.mjs` | المرور الثاني على SEO المنتجات ‏2026-09-28 | `AUDIT-PRODUCT-SEO-SECOND-PASS-2026-09-28.md/.json` |

التشغيل (من جذر المستودع): `node scripts/archive/audit-product-meta.mjs`
